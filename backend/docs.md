### 建议在项目里建一个 `docs.md` 文件：

#### 一、 数据库设计 (Database Schema)
*数据库文件：`evan.db`*

**1. 会话表 (`sessions`)** —— 用于左侧边栏列表
| 字段名       | 类型        | 说明                            |
| :----------- | :---------- | :------------------------------ |
| `id`         | VARCHAR/INT | 会话的唯一ID (主键)             |
| `title`      | VARCHAR     | 会话标题 (如："如何学习Python") |
| `created_at` | DATETIME    | 创建时间                        |

**2. 聊天记录表 (`chat_history`)** —— 用于保存具体的对话内容
| 字段名       | 类型        | 说明                                    |
| :----------- | :---------- | :-------------------------------------- |
| `id`         | INTEGER     | 消息的唯一ID (主键，自增)               |
| `session_id` | VARCHAR/INT | 关联的会话ID (外键)                     |
| `role`       | VARCHAR     | 角色：`user` (用户) 或 `assistant` (AI) |
| `content`    | TEXT        | 具体的聊天内容                          |
| `created_at` | DATETIME    | 消息发送时间                            |

*(注：如果你现在把所有东西都塞在了一个表里，强烈建议像上面这样拆分成两个表，逻辑会清晰很多！)*

#### 二、 API 接口文档

**1. 获取会话列表**
- **路径**: `GET /sessions`
- **功能**: 用户打开网页时，渲染左侧的历史会话列表。
- **请求参数**: 无
- **返回结果**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": "1",
      "title": "测试对话",
      "created_at": "2023-10-25 10:00:00"
    }
  ]
}
```

**2. 获取指定会话的历史记录**

- **路径**: `GET /history?session_id=xxx`
- **功能**: 点击左侧边栏的某个会话时，加载该会话最新的 20 条消息。
- **请求参数**: 
  - `session_id` (string, 必填): 会话的ID
- **返回结果**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！请问有什么可以帮你的？"}
  ]
}
```
